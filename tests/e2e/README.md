# Browser tests

Reserved for meaningful Playwright tests once the extension scaffold exists. Exercise the built extension with controlled fixtures and verify the resulting page behavior. Never submit real applications from automated tests.

Run npm run test:e2e to build and exercise the Chrome extension on fictional HTTPS forms. Queue coverage includes batch barriers, preset snapshots, user edits, pending Memories capture, simultaneous decisions, worker shutdown, a fresh browser session, missing forms, closed tabs and opening-page handshake recovery. Optional SCREENSHOTS writes synthetic proof images to an ignored local folder. No real application is submitted.
